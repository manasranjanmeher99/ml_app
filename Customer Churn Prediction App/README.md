# 📊 Customer Churn Prediction App

A Machine Learning-powered web application that predicts whether a customer is likely to leave a company based on customer demographics and account information. Built using **Python**, **Scikit-Learn**, and **Streamlit**.

## 🚀 Project Overview

Customer retention is critical for business growth. This application helps organizations identify customers who are at risk of churning, allowing proactive retention strategies.

Users can enter customer details through an interactive web interface and receive:

* Churn Prediction (Yes/No)
* Churn Probability Score
* Customer Risk Level
* Instant Results
