# 📰 Live News Dashboard

A modern real-time news dashboard built with Streamlit and NewsData.io API.

This application allows users to:
- Browse live international and national news
- Filter news by category and country
- Search for custom news topics
- Read full news articles
- View article images and publication details

---

# 🚀 Features

✅ Real-time live news updates  
✅ International & national news  
✅ Country-wise news filtering  
✅ Category-based news filtering  
✅ Search news by keyword  
✅ News images  
✅ Article descriptions  
✅ Publication dates  
✅ Direct article links  
✅ Responsive Streamlit dashboard

# ⚙️ Installation

## 1️⃣ Clone Repository

```bash
git clone <your-github-repo-link>
```

---

## 2️⃣ Open Project Folder

```bash
cd live-news-dashboard
```

---

## 3️⃣ Create Virtual Environment

```bash
python -m venv .venv
```

---

## 4️⃣ Activate Environment

### Windows

```bash
.venv\Scripts\activate
```

### Mac/Linux

```bash
source .venv/bin/activate
```

---

## 5️⃣ Install Requirements

```bash
pip install -r requirements.txt
```

---

# 🔑 Get Free API Key

Create a free account at:

https://newsdata.io

Copy your API key and replace:

```python
API_KEY = "YOUR_API_KEY"
```

inside `app.py`
