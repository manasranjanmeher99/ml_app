# 🏏 IPL Analytics Dashboard

An interactive IPL Cricket Analytics Dashboard built using Python, Streamlit, Pandas, and Plotly.

## Features
- Player Statistics
- Team Comparison
- Match Analytics
- Strike Rate Analysis
- Wicket Analysis
- Interactive Charts

## Tech Stack
- Python
- Streamlit
- Pandas
- Plotly

## Run Project

```bash
pip install -r requirements.txt
streamlit run ipl_analysis.py
