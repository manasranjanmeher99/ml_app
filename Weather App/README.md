# 🌦 Weather Analytics Dashboard

A modern **Weather Analytics Dashboard** built using **Python**, **Streamlit**, **Plotly**, and **Folium Maps** with:

- 🌧 Dynamic weather animations
- ⚡ Thunderstorm lightning effects
- ❄ Snow animations
- ☁ Weather-based background changes
- 📊 Interactive analytics charts
- 🗺 Live weather maps
- ✨ Glassmorphism UI
- 📱 Responsive modern design

# 📦 Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/weather-dashboard.git
cd weather-dashboard
```

---

## 2️⃣ Install Dependencies

```bash
pip install streamlit requests pandas plotly folium streamlit-folium
```

---

## 3️⃣ Add API Key

Get your free API key from:

👉 https://openweathermap.org/api

Replace this line inside `app.py`:

```python
API_KEY = "YOUR_API_KEY"
```

---

## 4️⃣ Run the Application

```bash
streamlit run app.py
```
